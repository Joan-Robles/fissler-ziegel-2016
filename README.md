# fissler-ziegel-2016

Proyecto sobre el artículo:

> Fissler, T. y Ziegel, J. F. (2016). *Higher order elicitability and Osband's principle*. The Annals of Statistics, 44(4), 1680–1707.

El artículo muestra que, aunque el Expected Shortfall (ES) no es elicitable por sí solo, el par (VaR, ES) sí es conjuntamente elicitable, y caracteriza la familia de funciones de puntuación consistentes para ese par.
